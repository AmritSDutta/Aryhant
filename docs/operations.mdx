# Operations & Deployment

## 1. Configuration Reference

All settings are managed via environment variables and loaded into the Pydantic `Settings` model in `src/chat_agent/config/settings.py`.

### Core Model & Execution
| Variable | Default | Description |
| :--- | :--- | :--- |
| `APP_NAME` | `"aryhant"` | Application name identifier |
| `MODEL_PROVIDER` | `"gemini"` | Model provider selection (`"gemini"` or `"nebius"`) |
| `USER_LLM_MODEL` | `"gemini-flash-lite-latest"` | Primary Gemini model identifier |
| `FIRST_CHOICE_MODELS` | `["gemini-flash-lite-latest", "gemini-2.5-flash"]` | Candidate models for Phase 1 randomized attempts |
| `FALLBACK_GPT_MODEL` | `"gpt-6-luna"` | OpenAI failover model identifier for Phase 2 |
| `USER_LLM_API_KEY` | `""` | Gemini API key (checked with `GEMINI_API_KEY` and `GOOGLE_API_KEY`) |
| `OPENAI_API_KEY` | `""` | OpenAI API key for `FALLBACK_GPT_MODEL` and search summarization |
| `NEBIUS_API_KEY` | `""` | Nebius Studio API key |
| `NEBIUS_BASE_URL` | `"https://api.tokenfactory.nebius.com/v1"` | Nebius Token Factory base URL |
| `NEBIUS_MODEL` | `"nvidia/Nemotron-3.5-Super-VL"` | Vision-language model identifier |

## 2. Local Commands

```bash
# 1. Editable package installation
python -m pip install -e .

# 2. Start FastAPI REST & Webhook Server
python -m uvicorn chat_agent.app:app --host 127.0.0.1 --port 8000

# 3. One-shot local CLI test
python -m chat_agent.main chat --message "Generate 5 Grade 5 math practice questions on fractions."

# 4. Start Slack Socket Mode Listener
python -m chat_agent.main slack
```

## 3. Docker Containerization

The repository includes a production `Dockerfile` running as a non-root user:

```dockerfile
FROM python:3.11-slim
ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1 \
    PORT=8000 \
    PYTHONPATH="/app/src:${PYTHONPATH}"
WORKDIR /app
RUN apt-get update && apt-get install -y --no-install-recommends build-essential curl ca-certificates fonts-noto-core && rm -rf /var/lib/apt/lists/*
RUN groupadd -r appgroup && useradd -r -u 10001 -g appgroup appuser
COPY requirements.txt /app/requirements.txt
RUN pip install --no-cache-dir -r /app/requirements.txt
COPY . /app
RUN chown -R appuser:appgroup /app
USER appuser
EXPOSE ${PORT}
CMD uvicorn chat_agent.app:app --host 0.0.0.0 --port ${PORT}
```

The `fonts-noto-core` package supplies Noto Sans Devanagari and Bengali fonts, required for Hindi/Bengali text in generated study-note and infographic PDFs on the Linux container.

## 4. Google Cloud Run Deployment

Deploy to Google Cloud Run with scale-to-zero configuration and Google Secret Manager integration:

```bash
# Build and push image
docker build -t gcr.io/YOUR_PROJECT_ID/aryhant .
docker push gcr.io/YOUR_PROJECT_ID/aryhant

# Deploy to Cloud Run
gcloud run deploy aryhant \
  --image=gcr.io/YOUR_PROJECT_ID/aryhant \
  --region=us-central1 \
  --cpu=2 \
  --memory=1024Mi \
  --min-instances=0 \
  --max-instances=1 \
  --timeout=600s \
  --port=8000 \
  --set-secrets=/app/secrets/.env=task-graph-secret:latest \
  --set-env-vars=DOTENV_LOCATION=/app/secrets/.env \
  --allow-unauthenticated
```

## 5. Cost Controls

- **Low-Cost Model**: Primary inference runs on `gemini-flash-lite-latest` with `MAX_OUTPUT_TOKENS=256`.
- **Fast-Path Moderation**: `IS_GEMINI_MODERATION_ENOUGH=true` bypasses external moderation API costs by leveraging native Gemini safety filters.
- **Event Filtering**: Discards non-mention channel traffic before triggering model execution.
- **Edge Scale-to-Zero**: Cloudflare Workers and Upstash QStash handle traffic bursts while Cloud Run remains at zero instances during idle periods.
